# たびのしおり

旅行の日程・持ち物・メモをひとまとめにする、「しおり」づくりのアプリです。
思いついた「やりたいこと」「行きたい場所」を左に書き出して、右の日程にドラッグして組み立てられます。
ブラウザだけで動作し、サーバーやアカウントは不要です。データは端末内にのみ保存され、電波がなくても使えます。

**公開URL**: https://bcno01.github.io/tabi-shiori/

## 主な機能

- **やりたいこと / 行きたい場所 → 日程にドラッグ**: 画面の左に、思いついたことを自由に入力して置いておけます。⋮⋮ をつかんで右の日程へドラッグすると予定に入り、日程の中での並べ替えも、左へ戻すのも自由です
  - PC(広い画面)は左右2ペイン。スマホは画面下の「やりたいこと・行きたい場所」バーを開くと下から出て、上の日程へドラッグできます。ドラッグが難しいときは、候補の「日程へ」ボタンで日を選んで入れられます
- **旅行の一覧**: 複数の旅行を管理。出発日が近い順に並び、「あと○日」「旅行中(2日目)」「終了」のバッジが付きます
- **旅行の切り替え**: 旅行画面の上部の旅行名(▾)をタップすると、一覧に戻らず別の旅行へ切り替えられます
- **アーカイブ**: 終わった旅行を一覧から隠せます(旅行メニュー →「アーカイブする」)。データは消えず、一覧の下の「アーカイブ済み」から開けて、いつでも戻せます
- **日程**: 日ごとに予定を追加。開始/終了時刻・種類(移動・食事・観光・宿泊・買い物・その他)・場所・費用・リンク・メモを記録できます
  - 並び順はドラッグで自由に決められます。時刻を入れて追加した予定は、時刻の合う位置に入ります。日の「•••」から「時刻順に並べ替える」もできます
  - 場所を入れると、タップで地図アプリが開きます
  - 日ごとの費用と旅行全体の合計を自動で集計
  - 予定の編集画面で別の日へ移したり、左の候補に戻したりできます。日の追加・削除も可能
  - 旅行中は今日の日が「今日」と表示され、開くと自動でそこまでスクロールします
- **持ち物**: チェックリストと進捗バー。「定番の持ち物を追加」で基本セットを一括追加
- **メモ**: 宿の予約番号・集合場所・緊急連絡先など、日程に入れにくい情報を見出し付きで保存
- **旅行中モード**: 今日が旅行期間内なら、日程の先頭に「今日・いま・次の予定(あと○分)」のカードが出ます。終わった予定は薄く、進行中の予定は強調表示。次の予定の場所は、地図と「現在地からの経路」をワンタップで開けます(1分ごとに自動更新。閲覧用リンクの画面でも出ます)
- **要確認の警告**: 時間が重なっている予定、時刻が前後している予定、場所が違うのに間が15分未満の予定に「要確認」の印が付きます(日の見出しにも件数)
- **元に戻す / やり直す**: 画面上部の ↶ ↷ や、Mac なら ⌘Z / ⇧⌘Z。ドラッグでの組み替え・削除・持ち物のチェックなど、旅行の中の操作はすべて対象です(最大60手。旅行を開き直すとリセット)。予定やメモを削除したときは、画面下の「元に戻す」でも戻せます
- **ルートを地図で開く**: 日の「•••」→「この日のルートを地図で開く」。場所の入っている予定を順につないで、Google マップ(全体・経由地つき)や、Apple マップ/Google マップ(区間ごと)で開きます。電車・バス/徒歩/車を選べます
- **カレンダーに書き出し(.ics)**: 旅行メニューから。iPhone / Mac のカレンダーに取り込めます。予定の30分前の通知も付けられるので、アプリを開いていなくても通知されます(PWA はアプリ自身では通知できないための代わりです)
- **閲覧用リンク**: 日程を「見るだけ」のリンクにして、友だち・家族に送れます(下記)
- **テキスト共有 / 印刷・PDF / 複製 / バックアップ**: LINEやメールにそのまま貼れるテキスト、紙・PDFのしおり、旅行のコピー、JSONファイルでの書き出し・読み込み

## 使い方

1. 一覧の「新しい旅行をつくる」でタイトル・出発日・日数を入力(出発日は未定でも大丈夫)
2. 「日程」タブの左側(スマホは下のバー)に「やりたいこと」「行きたい場所」を書き出す
3. ⋮⋮ をつかんで日程にドラッグして組み立てる。日ごとの「+ 予定を追加」から直接入れることもできます
4. 「持ち物」「メモ」タブで準備物や予約情報をメモ
5. 右上の「•••」から、カレンダー書き出し・閲覧用リンクの発行・印刷・複製・削除などができます。日の「•••」からは、その日のルートを地図で開けます
6. 旅行名をタップすると、別の旅行へ切り替えられます(タイトル・出発日の変更は、メニューの「旅行の情報を編集」か、切り替え画面の下のボタン)

最初に触ってみたいときは、一覧の「サンプルを見てみる」で例の旅行が入ります。

## 閲覧用リンク

旅行メニュー →「閲覧用リンクを発行」。リンクに含める内容を選んでコピー(または「送る」)します。

- リンクを開いた人は、アプリを入れていなくても、ブラウザで日程を**見るだけ**で見られます(編集はできません)
- 開いた人は「自分のしおりに取り込む」で、**編集できるコピー**を作れます。テキストでコピー、印刷/PDFも可能です
- 含める内容は選べます。初期状態は「日程 + 費用」だけで、**持ち物・候補・メモ(予約番号などが入りやすい)は含まれません**
- **発行した時点のスナップショットです。** あとから編集しても、送ったリンクには反映されません。変更したら、作り直して送り直してください
- **取り消しはできません。** リンクそのものに旅行のデータが入っている(サーバーには何も保存しない)ため、送ったリンクは永久に開けます。リンクを知っている人は誰でも見られるので、送る相手に注意してください
- リンクは旅行の大きさに応じて長くなります(目安: 3日間の旅行で約700〜1,500文字)。LINEなどで途中が切れるほど長い場合は、項目を減らすか、テキスト共有・PDFを使ってください

## インストール(PWA)

- **iPhone / iPad**: Safari で開き、共有メニュー →「ホーム画面に追加」
- **Mac**: Safari の共有メニュー →「Dockに追加」

**ホーム画面に追加して使ってください。** Safariのタブのまま使うと、しばらく開かなかったときにiOSがデータを消すことがあります。

## 技術構成

- 素のHTML/CSS/JavaScript(ビルド不要)、1ファイル(`index.html`)。外部ライブラリ・外部通信なし
- データは `localStorage` に保存(変更のたびに保存。直前の状態も予備として保持し、本体が壊れていたら自動で復元)
- ドラッグ&ドロップは Pointer Events で自前実装(iPhone の Safari では HTML5 の draggable が不安定なため)
- 元に戻す/やり直しは、操作のたびの旅行全体のスナップショット方式(メモリ上のみ)
- カレンダー書き出しは RFC 5545 の .ics を自前で生成(時刻はフローティング、75オクテットで折り返し、通知は `VALARM`)
- ルートは Apple マップ/Google マップの URL を組み立てるだけ(API キー・外部通信なし。リンクを開いたときだけ通信します)
- 閲覧用リンクは、旅行を JSON にして `CompressionStream`(deflate-raw)で圧縮し、URL の `#v=…` 以降に入れる方式。`#` 以降はブラウザからサーバーへ送られません。圧縮に未対応のブラウザでは無圧縮で作ります
- リンクの中身・読み込んだファイルは、項目ごとに検証・整形してから使います(展開後2MBまで)。ユーザーが入力した文字列は `textContent` で描画しており、HTMLとして解釈しません。リンクは `http(s)` のみ許可
- 地図は Apple Maps の検索URL(`maps.apple.com/?q=`)を開くだけです
- Service Workerでアプリ本体をキャッシュ(`sw.js`)。オフラインで起動できます
- GitHub Actionsで`main`ブランチへのpush時に自動デプロイ(`.github/workflows/pages.yml`)

## 注意事項

- **データは端末内にしかありません。** ブラウザのデータ消去やアプリの削除で消えます。大事な旅行は、出発前に「データ」から書き出しておくと安心です
- 端末をまたいだ自動同期はありません。別の端末へ移すときは、JSONファイルの書き出し/読み込みか、閲覧用リンク(→「取り込む」)を使ってください
- 時間の重なりなどの警告は目安です(移動時間は計算していません)。旅行中モードの「いま」は、終了時刻のない予定を、次の予定の開始まで(最後の予定は2時間)続くものとして扱います
- 複数人での同時編集はできません。みんなで決めるときは、誰かが編集して、閲覧用リンクで共有する使い方を想定しています
- 地図アプリを開く・リンクを開く操作には、そのときだけ通信が必要です
